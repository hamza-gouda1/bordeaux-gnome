# Wallpapers

Generated by `tools/make_wallpapers.py` (Pillow + numpy, deterministic, seed 20).
Original procedural work, licensed GPL-3.0-or-later with the rest of the repo.
No imagery, no downloads, no AI generation.

Motif: fine warped contour lines radiating from the lower right over a deep warm
gradient and burgundy glow, one sparing gold hairline arc, dithered grain.
Colours are read from `tokens/tokens.toml`.

- `<Variant>.jpg` 3840x2400, `<Variant>-1080p.jpg` 1920x1080 (lock screen)
- `grub/<Variant>.png` 1024x768 plain dark background (dark variants only)

Regenerate: `tools/make_wallpapers.py [--variant NAME] [--seed N] [--out DIR]`
