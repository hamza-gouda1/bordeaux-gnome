# Screenshots

Add these as PNGs (1920x1200 is fine) and they show up in the main README:

| File | What to show |
|---|---|
| `bordeaux-desktop.png` | Bordeaux, desktop with top bar and dock, one app window open |
| `bordeaux-overview.png` | Bordeaux, Activities overview with search results |
| `bordeaux-quick-settings.png` | Bordeaux, Quick Settings menu open |
| `oxblood-noir-desktop.png` | Oxblood Noir, same view as the first |
| `merlot-day-desktop.png` | Merlot Day, same view as the first |
| `boot.png` | GRUB menu or boot splash (photo of the screen is fine) |

Take them with the Print Screen key (GNOME saves to `~/Pictures/Screenshots`).
Hide personal things first: notifications, file names, browser tabs.
